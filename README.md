# RT SOP 알림

작업자 행동인식 기반 SOP 준수 시스템의 **관리자 알림 수신 앱**입니다.

엣지 PC가 카메라로 2인 1조 작업을 검출해 SOP와 대조하고, 편차(위반)가 확정되면 Firebase Cloud
Messaging(FCM)으로 이 앱에 알림을 보냅니다. 앱은 알림을 받으면 **알림 표시 + 진동 + 경고음 +
한국어 음성 안내(TTS)**를 재생해 관리자가 즉시 알아챌 수 있게 하고, "확인"을 누르기 전까지는
TTS 음성 안내를 반복해서 계속 알려줍니다.

전체 시스템 배경은 `장비_구매_기획안_1안_최종본_안전구역설정방식추가.pdf` 문서(5.5절 "관리자 휴대폰
알림 방식")를 참고하세요. 이 저장소는 그중 **관리자 폰 알림 앱** 부분만 다루며, 1차 MVP 범위입니다.

## 주요 기능

- FCM data 메시지 수신 시 알림 표시 · 진동 · 경고음 재생과 동시에 TTS 음성 안내 시작
  (`AlertFcmService` → `AlertPlayer`). **"확인"을 누르기 전까지 TTS는 10초 간격으로 반복**하고,
  말하는 동안에는 경고음을 25%로 낮춰(덕킹) 음성이 또렷하게 들리게 함
- 엣지 PC가 같은 위반이 해제됐다고(`kind="resolved"`) 알려오면 사람이 "확인"을 누르지 않아도 알람이
  자동으로 멈춤 — 이벤트 이력에는 사람이 직접 끈 "확인 완료"와 구분되는 "자동 해제"로 표시됨
- 경보상세 카드는 활성 경보가 있는 동안 확인 전까지 4초 간격으로 흔들림+스케일 애니메이션과 강한
  웨이브폼 진동을 반복 — 놓치기 어렵도록 의도적으로 강한 연출(진동은 설정 탭 스위치를 따름)
- 여러 위반이 동시에 활성 상태일 때: 카드는 항상 **심각도(중대 > 주의 > 일반) 우선**으로 가장 급한
  것을 보여주고, 나머지는 "다른 활성 위반 N건" 목록을 펼쳐서 확인 가능. 하나가 해제/확인되면 다음으로
  급한 위반이 사운드·TTS까지 포함해 자동으로 다시 울림. 미확인 위반이 여러 건이면 알림 트레이에도
  "확인 안 된 위반 N건" 그룹 요약 알림으로 묶여서 표시됨
- 자동 해제는 알람 없이 조용히 처리되지만, 경보상세 빈 화면에 "오늘 자동 해제된 위반 N건" 배지로
  안 놓치게 알려줌 (탭하면 오늘 이벤트로 이동)
- 경보음 크기 슬라이더 — 기기의 "알람" 볼륨 스트림에 직접 연결되어 있어, **소리가 재생되는 도중에도
  실시간으로 커지고 작아집니다**
- 기업용 톤에 맞춘 UI 리디자인 — 중대/주의/일반 심각도별 배지 색상 체계, IBM Plex Sans KR/Mono
  서체, 스트로크 스타일 아이콘, 카드형 화면(그림자 없이 1px 테두리)으로 통일. 시안(디자인 캔버스)
  출처와 세부 결정 사항은 [`DESIGN.md`](./DESIGN.md) 참고
- 하단 네비게이션 4화면 (아이콘만 표시 — 화면 이름은 상단 액션바에 "RT AUTOMATION" + 탭 이름으로 표시)
  - **홈** — FCM 토큰 표시/복사, 테스트 경보 재생, 경보음 볼륨 조절
  - **경보상세** — 현재 가장 급한 미확인 경보 표시(+ 나머지 활성 위반 펼치기), "확인(경보 종료)"
    버튼으로 즉시 알람 중지
  - **오늘 이벤트** — 커스텀 캘린더 그리드로 날짜를 골라 그날 발생한 편차 이력(등급 · 시간 · 내용 ·
    확인 상태) 조회. 좌우 화살표로 한 달씩 이동하거나, 가운데 월 표시를 누르면 연도를 바로 점프할 수
    있는 선택기가 뜸
  - **설정** — 경보음(시스템 알림음 선택), 음성 안내(TTS)·진동 켜고 끄기, 오늘 이벤트 전체 삭제,
    앱 버전 · 시스템 알림 설정 바로가기 — 카드가 아닌 구역 라벨 + 플랫 리스트 형태
- 실행 시 RT 로고 + "RT AUTOMATION" 문구가 서서히 나타나는 인트로, 액션바 아이콘으로 다크모드 전환
  (앱을 완전히 재시작하면 항상 라이트로 초기화 — 세션 한정 토글)
- `tools/send_test_alert.py` — 엣지 PC 없이도 실제 FCM 메시지를 바로 발송해볼 수 있는 테스트 스크립트

## 빠른 시작

1. Android Studio에서 프로젝트 열기 (또는 `gradlew.bat :app:assembleDebug`로 CLI 빌드)
2. Firebase 콘솔에서 `rtauto-sop` 프로젝트의 `google-services.json`을 `app/` 폴더에 배치
   (이미 저장소에 포함되어 있음 — 클라이언트 식별용 값이라 커밋해도 안전합니다)
3. 기기에 설치 후 실행 → 홈 화면에 표시된 FCM 토큰을 엣지 PC 설정에 등록
4. 엣지 PC 없이 테스트하려면 `tools/send_test_alert.py` 사용 (사용법은 스크립트 상단 주석 및
   `CLAUDE.md` 참고)

자세한 아키텍처 설명과 개발 명령어는 [`CLAUDE.md`](./CLAUDE.md)를 참고하세요.

## 현재 범위 밖 (기획안 대비 미구현)

- 30초 간격 미확인 재발송 — TTS 음성(10초 간격)과 진동(4초 간격, 경보상세 카드 흔들림과 함께)은
  반복되는 것으로 구현됨(위 참고). 알림과 경고음까지 같이 반복되는 전체 재발송은 아직 아님
- 잠금화면 위 전체화면 강제 경보
- 안전구역 기준점(마커) 로직 — 엣지 PC 쪽 영역이라 이 저장소 범위 아님
- 엣지 PC의 실제 발신 서버(FastAPI) — 현재는 `tools/send_test_alert.py`로 대체 테스트만 가능

2인 복귀 자동 해제(엣지 PC의 `kind="resolved"` 메시지로 사람 확인 없이 알람 종료)는 구현·실사용
테스트까지 완료됨 — 자세한 내용은 [`CLAUDE.md`](./CLAUDE.md)의 "Resolve path" 참고.
